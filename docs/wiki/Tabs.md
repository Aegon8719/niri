# 窗口组与分屏

Conscia 使用持久化 Dwindle 树管理分屏。小窗列中的一组应用共享一个槽位，点击可将整组提升到主区域；Super+左键或触屏向内滑动可将整组加入分屏。

新增应用始终从内侧进入，按目标区域宽高决定分割方向。加入的组按新区域宽高重算内部方向，保留成员顺序和比例。标题栏拖动调整分屏位置，分割线拖动调整比例。

`toggle-column-tabbed-display`（Mod+W）将主区域的额外分屏应用释放到小窗列。`maximize-column`（Mod+Ctrl+F）展开整个组，保留分屏。

组内应用图标按加入顺序排列在小窗组内侧底部；主区域不显示应用图标。详见[项目说明](../../README.md)。
